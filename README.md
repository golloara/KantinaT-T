# Kantina Breakfast & Bites — menú con pedidos por WhatsApp

Página web para celular: el cliente arma su pedido y lo envía por WhatsApp.

- Publicada con GitHub Pages: https://golloara.github.io/KantinaT-T/
- Número de WhatsApp: variable `WHATSAPP_NUMBER` al inicio del `<script>` en `index.html`.
- Platos, precios, categorías y opciones: lista `MENU` en `index.html` (copiar un plato y editarlo).
- Fotos: carpeta `img/`.
